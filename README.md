## 🧭Description
A simple games hub built with HTML5 and JavaScript and css. It was simply to demonstrate how to make a simple hub with search bar.
Just has two simple games made with HTML5 and JavaScript. Tic-Tac-Toe and Connect Four.

## 🎮 Features
Both game are to be played by two players. The games are simple and easy to play. The games are responsive and can be played on any device.
- Tic-Tac-Toe: A classic game where two players take turns marking a square in a 3x3 grid.
- Connect Four: A game where two players take turns dropping colored discs into a 7x6 grid. The first player to connect four discs in a row wins.

## 🚀 How to Play
1. Choose a game from the hub (Tic-Tac-Toe or Connect Four).
2. Follow the on-screen instructions for the selected game.
3. Tic-Tac-Toe: Click on a square to mark it with your symbol (X or O).
4. Connect Four: Click on a column to drop your disc.
5. Enjoy playing with a friend!

## 📦 Installation
Git clone the repository to your local machine.
And open the `index.html` file in any modern browser.
